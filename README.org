* hoyogacha.el
Emacs 中的米哈游抽卡记录管理器

* 目前功能
- [X] 支持国服相关数据
- [X] 获取抽卡记录链接
- [X] 自动抓取祈愿记录
  - [X] 拼接记录链接
  - [X] 实现轮询导入
- [X] 导入UIGF v4.1+ 标准的 json 数据
- [X] 保存数据到本地，以 UIGF v4.1+ 标准
- [X] 展示统计 buffer

* 使用例
** 依赖

本插件需要以下依赖：

[[https://github.com/alphapapa/plz.el][plz]]： 一个 Emacs 的 HTTP 客户端库。

请确保在您的 Emacs 配置中已经安装并加载了这些包。
** 安装与配置

将 =hoyogacha.el= 文件放置到您的 Emacs =load-path= 中。

在您的 Emacs 配置文件 (如 =init.el= ) 中添加以下代码：


#+begin_src elisp
(use-package plz :ensure t)
(require 'hoyogacha)
#+end_src

或者在31之后的Emacs中，通过内置的vc方式下载：
#+begin_src elisp
(use-package bangumi :demand t
  :vc (:url "git@github.com:TomoeMami/hoyogacha.el"
            :rev :newest))
#+end_src

如果愿意从我的自建ELPA 安装：
#+begin_src elisp
(add-to-list 'package-archives
                 '("TomoELPA" . "https://tomoemami.github.io/tomoelpa/snapshots/"))
(list-packages)
(package-install 'hoyogacha)
#+end_src
** 使用方法
配置用于存储数据文件的路径：
#+begin_src elisp
(use-package hoyogacha :demand t
  :custom
  (hoyogacha-data-save-file "/path/to/your/data.json"))
#+end_src

可选：配置自动导入的路径，启动时会从该路径中导入符合 UIGF 标准的 json 文件：
#+begin_src elisp
(use-package hoyogacha :demand t
  :custom
  (hoyogacha-data-save-file "/path/to/your/data.json")
  (hoyogacha-data-import-dir "/path/to/your/import/dir"))
#+end_src

可选：指定绝区零安装路径。
星穹铁道会自动扫描获取游戏安装路径，因此不需要指定。
#+begin_src elisp
(use-package hoyogacha :demand t
  :custom
  (hoyogacha-data-save-file "/path/to/your/data.json")
  (hoyogacha-data-import-dir "/path/to/your/import/dir")
  (hoyogacha-zzz-install-dir "D:/Apps/ZenlessZoneZero Game/ZenlessZoneZero_Data"))
#+end_src

可选：设置 UID 的展示名称，在下图这个例子中会将 =114514= 这个 UID 替换为 =野兽先生= ：
#+begin_src elisp
(use-package hoyogacha :demand t
  :custom
  (hoyogacha-data-save-file "/path/to/your/data.json")
  (hoyogacha-data-import-dir "/path/to/your/import/dir")
  (hoyogacha-zzz-install-dir "D:/Apps/ZenlessZoneZero Game/ZenlessZoneZero_Data")
  (hoyogacha-uid-aliases '(("114514" . "野兽先生"))))
#+end_src
设置好了这些之后直接 =M-x= 执行 =hoyogacha-show= 就行了，选择你需要处理的游戏。

拉取新记录在后台异步进行，不会阻塞 Emacs；可以先看到本地已有数据，拉取完成后统计 buffer 会自动刷新。中途可用 =M-x hoyogacha-cancel= 中止拉取（已拉取的部分仍会保存）。
** 已知问题
- 星穹铁道的 UBW 联动卡池抽卡记录链接与其他卡池不一样，因此打开 UBW 联动卡池抽卡记录时只能获取到联动卡池的抽卡记录，而打开其他卡池抽卡记录时能获取到其他抽卡记录。
