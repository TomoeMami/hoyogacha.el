* hoyogacha.el
Emacs 中的米哈游抽卡记录管理器

* 目前功能
- [X] 获取抽卡记录链接
- [ ] 自动抓取祈愿记录
- [X] 导入UIGF v4.1+ 标准的 json 数据
- [ ] 保存数据到本地，以 UIGF v4.1+ 标准
- [ ] 利用 VUI 规划界面并展示统计
